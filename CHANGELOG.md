# Changelog

All notable changes to FableBridge will be documented here.

## [0.1.0] - 2026-09-03

### Added

- Canonical Fable 5.1-inspired behavior profile.
- Native adapters for Claude Code, Codex, OpenCode, Cursor, and GitHub Copilot.
- Safe installer with dry-run support and explicit overwrite protection.
- Deterministic adapter renderer and sync check.
- Behavior/source mapping and Fable 5.1 cheatsheet.
- Launch kit and contribution guide.
- Standard-library test suite and GitHub Actions CI.

### Positioning

- Explicitly distinguishes transferable workflow behavior from model intelligence and capabilities.
- Makes no benchmark or model-equivalence claims.
