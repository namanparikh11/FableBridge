## Short launch post

Claude Fable 5.1's public prompting guidance contains several useful patterns for long-horizon coding agents: finish the whole task, batch independent tool calls, keep scope tight, make targeted edits, preserve continuity, and avoid idling while subagents work.

I packaged the transferable parts as **FableBridge** — one behavior profile rendered into native instructions for Codex, Claude Code, OpenCode, Cursor, and GitHub Copilot.

It does **not** claim to turn another model into Fable 5.1. It transfers workflow discipline, not intelligence.
